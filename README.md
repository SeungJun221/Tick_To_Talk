# Tick To Talk 온라인 플레이

1. 두 사람 모두 **OnlineWindows 폴더 전체**를 각자의 PC에 복사합니다. 예전 Windows/RelayTest 빌드를 섞어 사용하지 마세요.
2. `TickToTalk.exe` 실행 → **게임 시작** → 한 명은 **온라인 방 만들기** → 대기실의 **코드 복사**.
3. 친구는 같은 버전에서 **코드로 참가**. 두 사람 모두 **준비 완료**.

접속은 Unity Relay 영문·숫자 코드 방식만 지원합니다. IP 입력이나 별도 서버 실행은 필요 없습니다. 방장이 종료하면 방도 종료됩니다.

## 조작

- WASD 이동 / 마우스 시점 / **Shift 달리기 / Space 점프**.
- E: 폭탄·매뉴얼 조사, 마이크 발언 시작/종료. ESC: 설정 열기/닫기. 설정 중에도 멀티플레이 시간은 계속 흐릅니다.
- 상대방에게 걷기·달리기·점프 모션이 보입니다. 자기 캐릭터는 1인칭 시야에서 숨겨집니다. 동작 전송은 가벼운 별도 패킷으로 처리하고, 거울 렌더링 부담을 낮췄습니다.
- 게임 중 숫자 1 왼쪽의 ` 키로 둥근 감정표현 휠을 열고 마우스로 손 흔들기·환호·엄지 아래로 중 선택합니다. 상대방 화면에도 동기화됩니다. ` 또는 ESC로 닫습니다. 휠을 닫아도 시점이 갑자기 회전하지 않습니다. 양쪽 방의 출입문 옆에는 감정표현·태블릿 사용 안내판이 있습니다.

## 마이크

- **설정 → 오디오 → 보이스 채팅**의 입력 장치 버튼을 눌러 사용할 마이크를 선택합니다. 기본값은 Windows 기본 입력 장치입니다.
- **마이크 입력 테스트**를 누르고 말할 때 **입력 %**가 올라오는지 확인하세요. 이때는 장치 확인용으로만 녹음하며 상대에게 전송하지 않습니다.
- 라운드 중 유리 앞 나무 테이블 가까이에서 **E**를 누르고 **송신** 표시를 확인한 뒤 말하세요.
- 한 사람이 최대 10초 발언하고 두 사람 모두 10초 잠금됩니다. 수신자는 방 안 어디에서든 상대 목소리를 들을 수 있습니다. 음성 재생은 짧은 지터 버퍼를 사용해 순간적인 패킷 지연을 완화합니다.
- 입력이 계속 0이면 선택한 마이크와 Windows의 데스크톱 앱 마이크 권한을 확인하세요. 송신/수신 카운터로 전달 상태를 확인할 수 있습니다.
- 헤드폰 사용을 권장합니다. 자체 에코 제거는 포함하지 않습니다.

## 폭탄

- 내 폭탄의 힌트는 **상대방 방**에 있습니다. 내가 읽는 매뉴얼은 상대 폭탄용입니다.
- 4단계는 치환 → 배선 순서 → 좌표 찾기 → 동시 차단입니다. 이전 단계의 내 정답은 조사 화면 아래에 표시됩니다.
- 6자리 숫자로 입력하며 **앞자리 0도 포함**해야 합니다. 첫 단계는 **해독표 숫자 + 보정 숫자**의 일의 자리만 사용합니다. 역순 지시가 있으면 마지막에 뒤집습니다.
- 배선은 상대가 읽어 주는 문자 순서대로 단자 번호를 입력합니다. 좌표는 3×3 표에서 (행,열)의 숫자를 그대로 읽습니다. 이전 정답을 다시 계산에 사용하지 않습니다.
- 마지막 단계는 상대가 알려주는 차단 코드를 그대로 입력하고, 두 사람이 15초 안에 제출해야 합니다. 시간이 지나면 같은 코드로 다시 제출할 수 있습니다.
- 오답마다 20초 감소하며, 각 방에서 먼저 오답 3회를 기록하거나 5분이 지나면 실패합니다. 폭탄 전면의 축소된 주황·파란 단말 표시 위에 빨간 원형등 3개가 해당 방의 오답 수를 표시합니다. 오답 시 해당 방에 짧은 사이렌과 붉은 경고 조명이 켜집니다.
- 매뉴얼 보드 아래 벽에 고정된 초록 원형등 4개는 해당 방의 해제 진행도를 왼쪽부터 표시합니다. 유리 건너편에서도 서로의 진행 상황을 볼 수 있습니다.
- 중앙 유리의 마이크 안내판 아래 게이지는 사용 가능할 때 초록색, 발언 또는 잠금 중일 때 빨간색으로 표시됩니다. 발언 중에는 줄어들고 잠금 중에는 다시 찹니다.
- 실패 화면에서 **두 폭탄의 정답 · 풀이 보기**로 해당 라운드의 A/B 정답을 확인할 수 있습니다.

소스 프로젝트: `C:\UnityProject\Tick_To_Talk`.
빌드 메뉴: `Tick To Talk → Build Windows Online Client`.
출력: `Builds/OnlineWindows`.

## 설정과 캐릭터 꾸미기

- 제목 화면은 **Tick To Talk → 게임 시작 / 설정 / 캐릭터 꾸미기**로 구성됩니다.
- 그래픽 탭에서 전체 화면(모니터 해상도) / 창모드(1280×720)를 전환합니다.
- 오디오 → 사운드: 마스터, 음악, UI 볼륨. 음악 볼륨은 로비와 인게임 음악 모두에 적용되며, UI 소리는 버튼 클릭 시 재생됩니다.
- 오디오 → 보이스 채팅: 상대 음성 볼륨, 내 마이크 볼륨, 입력 장치, 로컬 입력 테스트. 테스트는 상대에게 보내지 않습니다.
- 적용/저장 또는 뒤로 가기로 설정을 저장합니다. ESC로 닫아도 저장됩니다. 설정을 닫으면 마이크 테스트도 중지됩니다.
- 캐릭터 꾸미기는 제목 화면에서 가능합니다. 멀티플레이 대기실에서는 설정·캐릭터 꾸미기 버튼을 표시하지 않습니다. 3D 미리보기를 회전하며 11개 항목, FREE 팩의 33개 선택지를 고를 수 있습니다.
- 외형 저장 또는 뒤로 가기로 외형을 저장합니다. 다음 실행에도 유지되며 접속 시 상대에게 전달됩니다.
- 전신 코스튬은 개별 의상과 함께 표시하지 않으며, 겹치는 헤어·바지 등은 자동으로 숨깁니다.
- 진행 중에는 외형 변경을 잠급니다. 로비에서 꾸미기를 마친 뒤 준비하세요.

점프 수정: 클립 자체의 상하 이동을 제거하고 도약 준비 구간을 잘라, 서버의 실제 점프 높이와 모션이 이중으로 적용되지 않도록 했습니다.

## 게임 종료 / 혼자 테스트
- 제목 화면의 게임 종료로 프로그램을 종료합니다. Unity 에디터에서는 플레이 모드만 종료합니다.
- 게임 시작 → 테스트 모드 · 혼자 시작: 인터넷/상대 접속 없이 시작하며 제한시간은 정지됩니다.
- V: 비행 켜기/끄기. WASD: 수평 이동, Space: 상승, Ctrl: 하강, Shift: 가속.
- 비행 중에는 벽·유리를 통과해 맵을 살펴볼 수 있습니다. V로 끄면 현재 X·Z 위치를 유지하고 바로 아래 바닥·테이블·옥상에 착지합니다. 착지 후 그 위치에서 걸어 다닐 수 있습니다.
- ESC 설정 → 테스트 종료로 접속 메뉴에 돌아갑니다. 비행은 온라인 멀티플레이에서는 활성화되지 않습니다.

## 음악 / 테스트 모드 상호작용
- 로비 Locked Glass와 인게임 Countdown Circuit은 직접 합성한 오리지널 반복 음악입니다. 게임 시작/종료 시 1.5초 동안 전환되며 발언 중에는 음악이 낮아집니다.
- 접속 메뉴 오른쪽 아래에서 혼자 테스트를 시작합니다. V로 반대편 방에 이동한 뒤 E로 해당 방 폭탄, 힌트, 마이크를 조사할 수 있습니다. 정답은 조사 중인 폭탄에 제출됩니다.

- 양쪽 감옥의 출입문 옆에 실시간 거울이 있습니다. 현재 캐릭터의 외형과 움직임이 반사됩니다. 접속 메뉴의 뒤로 가기로 첫 화면에 돌아갑니다.

- 양쪽 방 천장에 플레이어를 천천히 추적하는 CCTV와 깜빡이는 빨간 녹화 표시등이 있습니다(게임 내 감시 연출). 바닥의 색 띠와 이음선은 충돌 없는 장식으로, 바닥과 같은 높이로 이동합니다.

## 태블릿 메모장
- 게임 중 T로 태블릿을 열고 T, ESC 또는 닫기 버튼으로 닫습니다. 마우스 왼쪽 버튼을 누른 채 종이에 필기합니다.
- 펜 색상·굵기, 지우개, 실행 취소·다시 실행을 지원합니다. 메모는 개인 PC에 자동 저장되며, 모두 지우기는 확인 후 실행됩니다.
- 태블릿 사용 중 이동·점프·폭탄 제출은 중지되며, 라운드 시간과 상대 목소리 수신은 계속됩니다.
- 상대와 거울에는 양손으로 태블릿을 드는 모습이 보입니다. 내려놓을 때는 팔 동작 중간에 태블릿이 사라집니다. 메모 내용은 네트워크로 보내지 않습니다.
- 화면의 Wi-Fi 끊김 / 수신 불가는 외부와 연락할 수 없는 게임 속 설정입니다.

## 멀티플레이 안정화 업데이트 (2026-11-07)
- 이동 입력은 최신 순번만 처리하며, 수신 위치 사이를 100ms 버퍼로 보간합니다. 상호작용과 퍼즐 판정은 계속 방장이 검증합니다.
- 음성은 120ms 버퍼에서 패킷 순서를 복원하고, 짧은 누락 구간은 이전 음성을 감쇠해 연결합니다. 발언 시작 때 장치 초기화로 잘리지 않도록 라운드 중 입력 장치를 준비하며, 허용된 발언 시간에만 전송합니다.
- 거울은 보이는 동안 매 프레임 갱신하고 반사 카메라 좌표로 표시합니다. 해상도는 화면 너비에 맞춰 1024~2048px, 지원 시 4x MSAA를 사용합니다.
- 두 사람 모두 이번 빌드의 폴더 전체로 교체해야 합니다. 이전 실행 파일과 데이터 폴더를 섞지 마세요.

- 감정표현: 숫자 1 왼쪽의 백틱 키로 메뉴를 열고 표현을 클릭합니다. 엄지 아래로는 네 손가락을 접고 엄지만 아래로 폅니다.
- 각 방 문 옆 게시판에서 T 태블릿/감정표현 안내를 볼 수 있습니다. 가까이서 E를 누르면 상세 사용법을 열고, 다시 E로 닫습니다.
